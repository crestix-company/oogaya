# おおがさんち（大賀屋）

## 本番サイト

本番URLは **https://ogaya.pages.dev/** です。公開先は Cloudflare Pages です。
GitHub Pages の `crestix-company.github.io/oogaya/` は別の公開先であり、そちらの更新だけでは本番への反映確認になりません。

## 公開するファイル

このサイトは静的HTMLです。ビルドは不要です。

- `index.html` を公開ディレクトリの直下に配置します。
- `css/`、`js/`、`img/` を同じ階層に配置します。
- GitHubの作業ブランチは `main` です。Cloudflare側の連携先・本番ブランチは管理画面で確認してください。

公開後は **https://ogaya.pages.dev/** でトップ画像、ギャラリー、画像の拡大表示、PC・スマホの表示を確認してください。GitHubへのプッシュ完了とCloudflareでの公開完了は別々に確認します。

トップには元の `img/1.jpeg` を画質補正した `img/hero/original-roasted-sweet-potato.jpg` を使用します。PC・スマホともに同じ写真です。
